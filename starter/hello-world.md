# Hello World Example

This is a simple starter file to help you get started.

## Python Example

Create a file called `hello.py`:

```python
def greet(name):
    """Greet someone by name."""
    return f"Hello, {name}!"

if __name__ == "__main__":
    print(greet("World"))
```

## JavaScript Example

Create a file called `hello.js`:

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("World"));
```
