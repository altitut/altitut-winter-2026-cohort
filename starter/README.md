# Starter Code

This directory contains the starter code and templates for students.

## Getting Started

1. Make sure you're on your student branch: `student-winter-2026-{your-id}`
2. Navigate to this directory
3. Start working on your assignments here

## Structure

Students can organize their code however they prefer, but here's a suggested structure:

```
starter/
├── README.md          # This file
├── assignment-1/      # First assignment
├── assignment-2/      # Second assignment
└── projects/          # Personal projects
```

## Tips

- Commit your changes frequently
- Write clear commit messages
- Test your code before pushing
- Ask your instructor if you need help!
